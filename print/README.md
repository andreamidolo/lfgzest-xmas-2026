# Stampa · Christmas Dinner 2026 (27.11, Arbostora)

38 ospiti, 3 tavoli: **Tavolo 1 = 17 posti, Tavolo 2 = 9, Tavolo 3 = 12**. Nomi = soprannomi come nell'app.

Un solo file: `stampa-cena-natale-2026.pdf` (7 pagine A4, solo fronte, scala 100 %).

- **Pagine 1–2: 38 bigliettini nominali** per l'estrazione dall'ampolla (21 + 17), senza QR. Taglia sui segni.
- **Pagine 3–5: 3 segnaposto da tavolo** con il QR del sito ospiti. Piega a metà: sta in piedi a cavaliere. Meglio su cartoncino.
- **Pagina 6: scelte piatti** per ospite (antipasto, primo, secondo; dessert uguale per tutti).
- **Pagina 7: riepilogo cucina**: porzioni per piatto e chi le ha scelte.

## Rigenerare
`print/guests.json` = ospiti (nome, menu) esportati dall'app. `npm i && node print/build.js`.

# Stampa · Christmas Dinner 2026 (27.11, Arbostora)

38 ospiti, 3 tavoli: **Tavolo 1 = 17 posti, Tavolo 2 = 9, Tavolo 3 = 12**.

Un solo file: `stampa-cena-natale-2026.pdf` (5 pagine A4, solo fronte, scala 100 %).

- **Pagine 1–2: 38 bigliettini nominali** per l'estrazione dall'ampolla (21 + 17), senza QR. Taglia sui segni.
- **Pagine 3–5: 3 segnaposto da tavolo** con il QR del sito ospiti (scegli il tuo nome, la tua pagina, lascia la tua idea). Piega a metà sul segno laterale: sta in piedi a cavaliere. Meglio su cartoncino.

## Rigenerare
`npm i && node print/build.js`: ospiti, tavoli, tema (chiaro/scuro) e link in `build.js`.
